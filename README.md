# WaveQL

[![CI](https://github.com/jyrj/WaveQL/actions/workflows/ci.yml/badge.svg)](https://github.com/jyrj/WaveQL/actions/workflows/ci.yml)

**A joined debug store for agentic bug repair on an out-of-order RISC-V core.**
WaveQL gives an AI agent a failing BOOM core the way a hardware engineer would
want it: the waveform, the core's commit log and the golden Spike trace joined
on cycle in one queryable store, plus `why(signal, cycle)`, a causal walk over
the generated netlist. It ships as CHIA blocks, with **BuggyBOOM**, a benchmark
of 111 Chisel-source bugs in BOOM v3 where a repair counts only if the rebuilt
core passes twelve programs in lockstep with Spike.

Paper: [`paper/waveql-paper.pdf`](paper/waveql-paper.pdf) · A³ CHIA Hackathon, Track 1.

## Results

Measured on 669 scored episodes of `gemini-3.1-pro` over 111
BuggyBOOM tasks, every proposed patch verified by rebuilding the core:

| | WaveQL (joined store) | text control |
|---|---|---|
| verified repair rate (per task) | 17.9% | 21.7% |
| episodes repaired | 60 / 334 | 73 / 335 |
| tokens per episode | **378k** | 565k |
| tokens per verified repair | **2,105k** | 2,595k |

- **Comparable repairs for fewer tokens.** Repair-rate difference -3.8 points
  (95% CI [-8.8, +1.1]); WaveQL reads 0.67x the control's tokens per episode, 95% CI [0.60, 0.75], 111 paired tasks.
- **Navigation is the bottleneck.** With the store the agent proposed a patch in
  57% of episodes against
  71%; its most-used operation was a
  signal-name search.
- **Localization is a prior in an out-of-order core.** On 96 unseen bugs a
  fixed list of five hub files names the defect's file 45 times; the
  causal walk, 34.
- **Scale changes the answer.** On the first 11 tasks the joined view
  led by +10.6 points; at 111 the lead is gone.

Cost of the whole study: about **$863** of model
tokens and **$50** of cloud compute.

## Layout

| Path | Contents |
|---|---|
| `src/chia_waveql/` | CHIA blocks: `ChiselMutateNode`, `DetectabilityScreenNode`, `WaveQLIngestNode`, `WaveQLQueryTool`, `FixVerifyNode`, and the `waveql-loop` entry point |
| `src/waveql/` | The store, VCD and netlist ingest, the 12-operation query surface with `why`, the agent harness, the Chisel mutator, screening and repair verification |
| `scripts/` | Build (`build/`, `setup/`), run the study (`run/`), integrity checks (`check/`), scale out on GCE (`cloud/`) |
| `corpus/` | BuggyBOOM: one screen manifest per draw |
| `measurements/` | Every scored episode, verified patch and localization result; `transcripts.tar.gz` |
| `paper/` | Paper source and PDF, the numbers it is built from, and a showcase page |

## Reproduce the paper

Every number and figure is computed from `measurements/`:

```bash
pip install -e '.[test]'
pytest
scripts/run/build_all.sh           # needs typst and pdfinfo
python scripts/check/final_integrity.py
```

## Run the loop

```bash
scripts/setup/10_conda.sh && scripts/setup/11_conda_tuning.sh
scripts/build/00_patch_chipyard.sh && scripts/build/05_install_scala.sh
scripts/build/10_chipyard.sh && scripts/build/20_sim.sh && scripts/build/30_netlist_snapshot.sh
pip install -e '.[agents]' && cp configs/gcp.env.example configs/gcp.env   # Vertex AI project
waveql-explain <mutant-id>                                   # one failure, explained
scripts/run/screen_parallel.sh 4 5                           # screen a draw of mutants
python scripts/run/scale.py agents --tag run --seeds 1 2 3   # agent episodes
python scripts/run/scale.py verify --tag run --worker var/workers/w1
python scripts/run/headline.py                               # repair rates by arm
```
